## 源码级补充核验

- 幽灵变量零定义：`grep -rn "\-\-bg-default:" app/src` 等均无命中；
  使用方为四个 `Review*.vue` + `MessageItem.vue`(1043-1065) +
  `GroupChatConfigModal.vue`（后者待查是否同病，迁移时顺手确认）。
- `NodeListView.vue:311` `.node-card__dot[data-status="online"]
  { background: #22c55e }`，而 `--color-status-success: #4ade80`
  已在 @theme 定义。
- `.msg-speaker-chip`（MessageItem.vue:1038-1067）用 `--ev-color-*`
  fallback（#2a2a2a/#e0e0e0/#444/#555/#4a8eff）；仅群聊渲染，当前 DB 无
  group 会话 → 休眠债，不入本任务。

## 复现注意事项（踩过的坑）

1. `create_session` 不接受 `title` 字段（会静默忽略，标题默认"新对话"）。
2. 面板门控链：会话行 `workflow_enabled && plugin_name=='review'` →
   `get_current_task_slug(project_path=current_cwd)` 命中
   `.everlasting/tasks/*/task.json` → `get_review_state(slug)` 返回
   `kind:"state"`。任一环断掉则面板静默隐藏（missing 不报错）。
3. `.review-matrix__collapse` 是"收起整个 body"，不是展开行；展开 finding
   明细要点 `.review-matrix-grid__cell--body`（toggleCell）。
4. 清理必须走 `delete_session` API + 删 json 文件；直写 DB 需先停 daemon。
